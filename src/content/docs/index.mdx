## What ASD adds to your repo

Every function gets three things: a decision ledger, an effect declaration, and a place in the call graph. All checked into git via a compact `.asd/conclusions/` sidecar. All queryable by the coding agents that write the code.

<CardGrid>
  <Card title="Decision Ledger" icon="pencil">
    Append decisions, hazards, rationale, and constraints to any symbol. Entries survive renames. Approve, reject, or withdraw.
  </Card>
  <Card title="Effect Declarations" icon="warning">
    17 categories (`io.fs.read`, `io.net.out`, `io.db.write`, …). Declared per symbol, propagated transitively through the call graph.
  </Card>
  <Card title="Semantic Index" icon="magnifier">
    Every function, method, and class parsed by tree-sitter. 9 languages: Python, TypeScript, Rust, Go, Java, C#, Ruby, Kotlin, Swift.
  </Card>
  <Card title="Call Graph" icon="random">
    Intra- and cross-module edges. Transitive effects propagate automatically.
  </Card>
  <Card title="Policy Gate" icon="approve-check-circle">
    File-backed JSON rules: allow, deny, or require-approval per action and actor kind.
  </Card>
  <Card title="Ratification" icon="approve-check">
    Approve, reject, or withdraw ledger entries. Full approval workflow.
  </Card>
  <Card title="Audit Event Stream" icon="list-format">
    Hash-chained JSONL log of every ledger mutation and policy evaluation.
  </Card>
  <Card title="Git-native Sidecar" icon="seti:folder">
    The compact committed sidecar (decisions, hazards, recipes, …) lives in `.asd/conclusions/*.jsonl` — checked into git, travels with every clone.
  </Card>
  <Card title="Agent Thinking" icon="comment">
    Hypotheses, mental models, failed attempts, and open questions — stored per symbol, surfaced automatically by `prepare-change`, and shared across sessions via git.
  </Card>
</CardGrid>

## Surfaces

- **`asd`** — CLI: `onboard`, `init`, `index`, `read`, `ledger`, `think`, `impact`, `prepare-change`, `worktree`, `sync`, `hydrate`, `audit`, `hooks`, `mcp`, `skill`, `watch`, `help`, `bootstrap`
- **`asd-mcp`** — stdio MCP server exposing 64 tools to coding agents
- **`asd-serve`** — HTTP server + Lens review UI
